# Navigator demo – Copy-paste for Week 2 app

Use during **Phase 1** of the teaching path (Navigator first).

1. **Create** `task_manager_app/lib/second_screen.dart` and paste the contents of **`second_screen.dart`** from this folder.
2. **Edit** `task_manager_app/lib/home_page.dart`:
   - Add import: `import 'second_screen.dart';`
   - Add the button snippet from **`home_page_add_button.txt`** inside the `Column`’s `children`.

Run the app: tap "Go to Second Screen" (push), then "Go Back" (pop).
