- **In class:** Open the relevant file and walk through the diagrams; use as a slide or shared screen.
- **Self-study:** Read in order for a clear mental model of cross-platform and Flutter’s approach.
- **Diagrams:** Rendered best in a Markdown viewer that supports **Mermaid** (e.g. GitHub, VS Code with Mermaid extension, or [mermaid.live](https://mermaid.live)).
